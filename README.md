# 시간표 랜덤 추천기

개설된 강의에 한하여 시간표를 가져와, 사용자가 제시한 조건에 맞는 시간표를 랜덤으로 생성합니다.
그렇게 된다면 추후 시간표를 맞춰볼 필요없이 자동으로 만들어진 것에서 골라서 수강신청을하면 된다.
특히 해당과목의 수강신청이 실패했을 경우에 추천하는 대체과목도 알려주도록 설정한다.



## 설계

데스크탑 애플리케이션을 GUL 방식으로 설계 및 구현해야함.

프로젝트 이름: 시간표 추천 시스템 

---
### 상세 기능

#### 시간표 클릭 시
- JTable에 시간표 출력
- 해당 과목 리스트 표시

#### 과목 클릭 시
- 과목 상세 정보 출력

#### 수강 실패 시
- 대체 과목 추천 기능
  - 같은 학과
  - 같은 과목 구분
  - 유사 과목 기반 추천
